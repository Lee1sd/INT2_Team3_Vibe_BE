# 커리어 던전 Backend

이력서를 기반으로 AI 면접관과 실전형 기술 면접을 연습하는 게임형 서비스 **커리어 던전**의 백엔드 저장소입니다.

## 주요 기능

- 이메일과 비밀번호를 이용한 회원가입 및 로그인
- PDF, TXT, MD 형식의 이력서 업로드와 텍스트 추출
- 이력서 내용과 면접관 페르소나를 반영한 질문 생성
- 답변 평가 및 기준 미달 시 꼬리질문 1회 생성
- 최종 충족률과 면접관 해금 상태 관리
- 면접 세션과 대화 기록 저장

## 기술 스택

- Java / Spring Boot
- Spring Data JPA
- MySQL
- AWS S3
- Apache PDFBox
- LLM API (인터페이스 추상화 후 벤더 선정 예정)

## 개발 구조

Spring Boot 모놀리식 애플리케이션 안에서 인증, 파일, 면접 엔진, 평가 도메인을 분리해 개발합니다. LLM 호출부는 인터페이스로 추상화하여 실제 API와 Mock 구현을 교체할 수 있도록 구성할 예정입니다.

## 개발 상태

현재 MVP 개발 준비 단계입니다. 세부 API와 실행 방법은 프로젝트 구현에 맞춰 추가할 예정입니다.
