## 이 표를 읽는 방법

- **1주차 산출물은 "API 명세 확정"**이다. 즉 1주차 종료 시점에는 `docs/api/api-spec.md`
  기준 계약이 팀 전체 합의로 잠겨 있어야 하고, 이후 임의로 필드를 바꾸지 않는다
  (바뀌면 이 저장소의 `docs/api/api-spec.md`를 먼저 갱신 후 코드를 맞춘다).
- **2주차 산출물은 "E2E 프로토타입"**이다. 이 시점에 LLM 실연동 테스트가 처음
  이루어진다(`docs/operations/llm-cost-policy.md` §3 세부 모델 확정 시점과 일치).
- **3주차 산출물은 "MVP 완료"**이며, `docs/operations/failure-policy.md` §4의
  "4주차 개발 침범" 리스크 대응에 따라 3주차 종료 시 기능을 동결(Feature Freeze)한다.
- **4주차는 버그픽스/QA/리허설/회고만** 한다. 새 기능을 4주차에 넣지 않는다.
